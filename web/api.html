① 你的凭证（HMAC token）

选手接口（/api/v1/round、/api/v1/guesses、/api/v1/leaderboard）需要请求头 Authorization: Bearer <token>。token 就是你的身份，别外传；有效期由服务端配置决定，默认 2 小时。 过期或刷新本页后需重新登录，回到比赛页再点击 API 链接获取新 token，成绩不受影响。

② 规则

  • 每人每轮由服务端分配一个 5 字母小写答案，猜测必须落在下面的合法猜词表里，同一轮不能重复猜同一个词。
  • result 是 5 位标记串：0 答案里没有这个字母；1 有但位置不对；2 位置正确（重复字母按标准 Wordle 语义）。全 2 即解出。
  • 名次按 步数少 → 用时短 → 提交早 → sub 小 比；只有已解出的人上榜。被拒的猜测不计步、不计时。
  • 用时 = 第一次被接受的猜测 → 解出那一刻。两次被接受的猜测间隔至少 1s（1 次/秒），脚本请自行 sleep。

③ 接口

方法与路径鉴权说明
GET /api/v1/roundBearer{"state":"waiting|open|closed","roundNo":7}
POST /api/v1/guessesBearer请求 {"guess":"crane"}；响应 {"result":"01202"}
GET /api/v1/leaderboardBearer{"roundNo":7,"entries":[{"rank":1,"displayName":"…","attempts":3,"elapsedMs":4120}],"me":{"solved":true,"rank":1,"attempts":3,"elapsedMs":4120}}
GET /words/answers.txt无答案池 2315 个词，每行一个
GET /words/valid.txt无合法猜词 12972 个词，每行一个（含答案池）

错误码：bad_length / not_in_word_list / already_guessed（400）、 unauthorized（401，回来换 token）、round_not_open / expired / already_solved（409）、 too_many_requests（429，发太快）。错误响应形如 {"error":"not_in_word_list"}。

④ 请求封装（Python）

#!/usr/bin/env python3
"""请求封装：把下面的函数复制进你的脚本即可。"""
import json, urllib.request

BASE = "$BASE"
TOKEN = "$TOKEN"


def call(path, body=None):
    """GET/POST 一个接口，返回解析后的 JSON。出错会抛 HTTPError，
    e.read() 里是 {"error":"..."}。"""
    req = urllib.request.Request(
        BASE + path, method="POST" if body is not None else "GET",
        data=json.dumps(body).encode() if body is not None else None,
        headers={"Authorization": "Bearer " + TOKEN, "Content-Type": "application/json"})
    with urllib.request.urlopen(req) as r:
        return json.load(r)


def round_state():
    """{"state":"waiting|open|closed","roundNo":7}"""
    return call("/api/v1/round")


def guess(word):
    """{"result":"01202"}，全 2 即解出。"""
    return call("/api/v1/guesses", {"guess": word})


def leaderboard():
    """{"roundNo":7,"entries":[...],"me":{...}}"""
    return call("/api/v1/leaderboard")


def load_words(name="valid"):
    """name: "valid"（合法猜词）或 "answers"（答案池），返回词表 list。"""
    with urllib.request.urlopen(BASE + "/words/" + name + ".txt") as r:
        return r.read().decode().split()

① 你的凭证（HMAC token）

选手接口（/api/v1/round、/api/v1/guesses、/api/v1/leaderboard）需要请求头 Authorization: Bearer <token>。token 就是你的身份，别外传；有效期由服务端配置决定，默认 2 小时。 过期或刷新本页后需重新登录，回到比赛页再点击 API 链接获取新 token，成绩不受影响。

② 规则

  • 由管理面板开赛时选玩法：轮次赛（一轮一题，解出即收工，按步数 / 用时排名）或 限时赛（限时内答对一题立刻换下一题继续答，按答对题数排名，时间到自动收场）。
  • 每人的当前题由服务端分配一个 5 字母小写答案；限时赛答对后分配下一题。猜测必须落在下面的合法猜词表里，同一题不能重复猜同一个词。
  • result 是 5 位标记串：0 答案里没有这个字母；1 有但位置不对；2 位置正确（重复字母按标准 Wordle 语义）。全 2 即答对当前题。
  • 轮次赛名次按 步数少 → 用时短 → 提交早 → sub 小 比；限时赛名次按 答对题数多 → 达到该题数早 → 累计步数少 比。只有答对过至少一题的人上榜。被拒的猜测不计步、不计时。
  • 榜单和历史成绩的口径与玩法无关：步数 = 累计被接受的猜测次数，用时 = 累计净解题用时（各题用时之和，不含换题之间的空档）。个人进度与猜测响应的 attempts 则是当前题步数，个人进度的 totalAttempts 是累计步数。
  • 两次被接受的猜测间隔至少 1s（1 次/秒），两种玩法都一样，脚本请自行 sleep。
  • 限时赛答对后服务端立刻换新题，响应里的 solved:true + solvedCount 就是信号：清空自己的棋盘接着猜下一题即可，不必重新拉取配置。

③ 接口

方法与路径鉴权说明
GET /api/v1/roundBearer{"state":"waiting|open|closed","roundNo":7,"mode":"round|timed","openedAt":0,"durationMs":600000,"endsAt":1712345678901,"serverNow":1712345678901,"playing":3,"solved":5}：endsAt 为 0 表示非限时赛；倒计时请用 endsAt - (serverNow + 本地流逝时间)，别信本机时钟
POST /api/v1/guessesBearer请求 {"guess":"crane"}；响应 {"result":"01202","solved":false,"solvedCount":2,"attempts":3,"elapsedMs":0}。限时赛 solved:true 即已换下一题
GET /api/v1/leaderboardBearer{"round":{"state":"open","roundNo":7,"mode":"timed","openedAt":1712345078901,"durationMs":600000,"endsAt":1712345678901,"serverNow":1712345500000,"playing":3,"solved":5},"entries":[{"rank":1,"displayName":"…","solvedCount":6,"attempts":38,"elapsedMs":271000}],"me":{"solved":false,"rank":1,"attempts":3,"totalAttempts":38,"solvedCount":6,"elapsedMs":0}}；round、entries 和 me 来自同一次快照，轮询这个接口即可。轮次赛榜单行的 solvedCount 恒为 1，个人进度 me.solvedCount 为 0 或 1；未上榜时 rank 为 0
GET /words/answers.txt无答案池 2315 个词，每行一个
GET /words/valid.txt无合法猜词 12972 个词，每行一个（含答案池）

错误码：bad_length / not_in_word_list / already_guessed（400）、 unauthorized（401，回来换 token）、round_not_open / expired（409，expired 在限时赛里表示时间到） / already_solved（409，只有轮次赛会出现）、too_many_requests（429，发太快）。 管理接口另可能返回 bad_request / bad_mode / bad_duration（400）。错误响应形如 {"error":"not_in_word_list"}。

管理开赛接口 POST /api/v1/admin/round/open 必须提交 JSON 并显式指定玩法： {"mode":"round"} 或 {"mode":"timed","durationSec":600}。 限时赛时长为 30 ~ 21600 秒；成功返回与 GET /api/v1/round 相同结构的场次快照。

④ 请求封装（Python）

#!/usr/bin/env python3
"""请求封装：把下面的函数复制进你的脚本即可。"""
import json, urllib.request

BASE = "$BASE"
TOKEN = "$TOKEN"


def call(path, body=None):
    """GET/POST 一个接口，返回解析后的 JSON。出错会抛 HTTPError，
    e.read() 里是 {"error":"..."}。"""
    req = urllib.request.Request(
        BASE + path, method="POST" if body is not None else "GET",
        data=json.dumps(body).encode() if body is not None else None,
        headers={"Authorization": "Bearer " + TOKEN, "Content-Type": "application/json"})
    with urllib.request.urlopen(req) as r:
        return json.load(r)


def round_state():
    """{"state":"waiting|open|closed","roundNo":7,"mode":"round|timed",
    "endsAt":1712345678901,"serverNow":1712345678901,...}"""
    return call("/api/v1/round")


def guess(word):
    """{"result":"01202","solved":false,"solvedCount":2,"attempts":3}
    限时赛里 solved 为 True 表示这题刚答对、服务端已换下一题：
    清空自己的棋盘，接着用同一个循环猜新题即可。"""
    return call("/api/v1/guesses", {"guess": word})


def leaderboard():
    """{"round":{...},"entries":[...],"me":{...}}，一次读取场次与成绩。
    entries 按 round.mode 排序：限时赛看 solvedCount，轮次赛看 attempts/elapsedMs。"""
    return call("/api/v1/leaderboard")


def load_words(name="valid"):
    """name: "valid"（合法猜词）或 "answers"（答案池），返回词表 list。"""
    with urllib.request.urlopen(BASE + "/words/" + name + ".txt") as r:
        return r.read().decode().split()
